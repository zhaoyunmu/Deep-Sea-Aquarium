🐟 万灵缸 · 生存指南

  • 分享 — 在水里任意点一下，撒下食物，鱼群会游过来吃。鱼吃饱后会产出发光尘。
  • 神秘卵 — 攒够发光尘，点右上角「神秘卵」，一枚卵会沉到海底。点击它，就能孵化出一条新鱼。
  • 聊天 — 点击任意一条鱼，它会游过来和你说话。每条鱼都有自己的名字和性格。
  • 搅水 — 鼠标快速划过，会带动水流，鱼和海草会跟着移动；划得快，还能点亮夜光藻。
  • 拍水 — 双击水面，会激起一圈水纹，把附近的鱼轻轻惊散。
  • 漂流瓶 — 有时会有漂流瓶沉下来，点击它，就能读到瓶里的句子。
  • 路过的鱼 — 偶尔有旅人鱼游过（下雨天更多），点击它聊两句——它聊完还要赶路。
  • 图鉴 — 右上角「图鉴」，查看你收集到的各种深海生物。
  • 昼夜天气 — 海里有昼夜交替和天气变化。入夜后生物光更亮，暴雨天鱼会躲到深处，偶尔有闪电落下。

🐋 鲸之石

密语一旦刻入，立即生效

传说有一条巨鲸，
把深海（ deep sea ）的智慧刻进了这块石头。
若以独特的密语呼唤它——石纹亮起之时，
这片海洋便有了会说话的灵魂。

  1. 打开 platform.deepseek.com，注册 / 登录（新账号会送一笔免费额度）。
  2. 左侧菜单选「API keys」→ 点「创建 API key」，复制那串 sk- 开头的密钥（只显示一次，记得保存好）。
  3. 回到这里，把密钥粘贴进下方「API Key」输入框，点「💾 保存并生效」。
  4. 右下角的鲸之石亮起 = 成功。从此聊天、起名、遗言，都有了灵魂。
  5. 费用可忽略：一次对话只有几十 token，几毛钱能聊很久很久。

密语只保存在你本机的 .env 文件里，界面上永远只显示尾号。换别家模型只要地址兼容 OpenAI 接口即可。
