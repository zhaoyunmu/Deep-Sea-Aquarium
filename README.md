# 🌊 万灵缸 · 深海互动水族馆

一片会呼吸的深海，一群有名字的灵魂。

Canvas 手绘的深海世界：体积光柱、海雪、水母、boids 群游鱼群，以及 **DeepSeek 驱动的、每条都有自己名字和性格的鱼**。

## 运行

```bash
# 1. 把你的 DeepSeek key 填进 .env（可选，不填也能玩，鱼会用离线人格）
#    DEEPSEEK_API_KEY=sk-xxxx

# 2. 启动（零依赖，Node ≥ 18）
node server.js

# 3. 打开
#    http://localhost:3000
```

## 玩法

| 操作 | 效果 |
| --- | --- |
| 点击水面 | 投喂饲料，鱼群涌来抢食，进食产出**发光尘** |
| 点击小鱼 | 它会游过来和你聊天（AI 生成性格对话） |
| 右上角「神秘卵」 | 花 30 发光尘孵化随机物种，稀有度越高越难出 |
| 点击沉底的卵 | 孵化！新物种自动记入**万灵图鉴** |
| ✨ 生成档案 | 让 AI 为鱼重新起名、写性格 |
| 什么都不做 | 看光柱、海雪、水母呼吸……偶尔有鲸影路过 |

- 图鉴进度 / 发发光尘 / 投喂次数 存在浏览器 `localStorage`，换浏览器不共享。
- 物种：常见 → 罕见 → 稀有 → 史诗 → 传说（鎏金锦鲤、月带皇带鱼……），还有一位不收录的神秘访客。

## 技术备注

- 纯原生 Canvas 2D + ES Modules，无构建、无 npm 依赖。
- `server.js` 只做两件事：托管静态文件 + 把 `/api/chat` 代理给 DeepSeek（key 不进浏览器）。
- AI 不可用时自动降级为离线人格（随机名字 + 预设性格），随时可切换。
- 想调难度：`public/js/main.js` 里的 `EGG_COST`、`MAX_FISH`；物种数值在 `public/js/species.js`。
