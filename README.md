# 🌊 万灵缸 · 深海互动水族馆

一片会呼吸的深海，一群有名字的灵魂。

Canvas 手绘的深海世界：体积光柱、海雪、水母、boids 群游鱼群，以及 **DeepSeek 驱动的、每条都有自己名字和性格的鱼**。

## 运行

```bash
# 1. 把你的 DeepSeek key 填进 .env（可选，不填也能玩，鱼会用离线人格）
#    DEEPSEEK_API_KEY=sk-xxxx

# 2. 启动（零依赖，Node ≥ 18）
node server.js

# 3. 打开
#    http://localhost:3000
```

- 服务器默认只监听本机（`127.0.0.1`），防止局域网设备滥用你的 API key。确有局域网访问需求，在 `.env` 里加 `HOST=0.0.0.0`。
- key 也可以进游戏后在右下角**鲸之石**面板里直接填，即时生效并写回 `.env`。

## 玩法

| 操作 | 效果 |
| --- | --- |
| 点击水面 | 投喂饲料，鱼群涌来抢食，进食产出**发光尘** |
| 点击小鱼 | 它会游过来和你聊天（AI 生成性格对话） |
| ✏️ 改名 | 给鱼起名字——**性格与说话习惯会随新名字与物种重新落定** |
| 右上角「神秘卵」 | 花 30 发光尘孵化随机物种，稀有度越高越难出 |
| 点击沉底的卵 | 孵化！新物种自动记入**万灵图鉴** |
| 漂流瓶 | 沉底的瓶子点开有深海拾句，收进背包可改写、可再放飞 |
| 音乐盒 | 海里偶尔沉下《曲名》音乐盒，奏乐替代背景乐；点它收回背包，拖回海里继续放 |
| 星辰 | 鱼儿寿终后会钻进沙床长眠，一颗带遗言的星辰随之落下 |
| 什么都不做 | 看光柱、海雪、水母呼吸……偶尔有鲸影路过；左下角石板是时钟 |

- 昼夜各 10 秒/小时（一整天 4 分钟），有晴 / 小雨 / 暴风雨 / 闪电；火烧云预告天气——朝霞不出门，晚霞行千里。
- 图鉴进度 / 发光尘 / 背包存在浏览器 `localStorage`，换浏览器不共享。

## 存档

- **自动存档**：鱼群与卵每 8 秒写入浏览器。
- **手动存档槽**：右下角「💾 存档 / 📖 读档」，整缸状态（鱼、卵、发光尘、图鉴、天气、漂流瓶、星辰、音乐盒）一键回到那一刻。
- **导出 / 导入**：设置面板里可把整缸进度导出成 JSON 文件——备份，或发给朋友"捞一捞你的缸"。

## 音乐盒 🎵

1. 把音乐文件放进 `public/audio/box/`（支持 mp3 / ogg / wav / flac / m4a）。
2. 文件名（不含扩展名）就是曲名，海里会沉下《曲名》音乐盒，**单曲循环**。
3. 想要封面：放一张和音频同名的图片（jpg / png / webp / gif），例如「夜曲.mp3」+「夜曲.jpg」。

盒子在海里时，它的曲子会替代背景音乐；收回背包即静、背景乐回落。鱼群也爱围着听歌。同屏最多两只，最新的一只在响。放好文件后 1 分钟内自动识别，无需重启。

## 技术备注

- 纯原生 Canvas 2D + ES Modules，无构建、无 npm 依赖。
- `server.js` 托管静态文件 + 把 `/api/chat` 代理给 DeepSeek（key 不进浏览器）+ 列出音乐盒曲目（`/api/tracks`）。
- 持久化键名与存读档逻辑集中在 `public/js/save.js`；渲染与玩法在 `main.js`，音乐盒实体在 `musicbox.js`。
- AI 不可用时自动降级为离线人格（名字 + 物种共同决定性格），随时可切换。
- 想调参数：`public/js/main.js` 里的 `EGG_COST`、`MAX_FISH`；物种数值在 `public/js/species.js`；音乐盒大小在 `musicbox.js` 的 `BOX_SIZE`。

## 开发者指令（Dev Mode）

在和**沫沫**（年轻水母）的聊天框里输入以 `/` 开头的指令，可以直接拨弄这片海——**本地执行，不消耗 AI token**，离线也能用。沫沫也能听懂自然语言（如"能帮我变回晴天吗"），她会在回复里嵌入指令自动执行。

| 指令 | 效果 |
| --- | --- |
| `/help` | 列出所有指令 |
| `/weather <晴\|小雨\|暴雨\|自动>` | 切换天气（也认 clear/rain/storm/auto） |
| `/fire <黎明\|黄昏>` | 让下一个黎明 / 黄昏必为火烧云 |
| `/time <14 \| 2pm \| 黄昏 \| +2>` | 跳到指定时辰；`/time day 5` 改总天数 |
| `/whale` | 立刻放一只鲸影游过 |
| `/bottle [字条]` | 降一只漂流瓶（可带自定义字条） |
| `/musicbox <序号 \| 关键词>` | 降一只音乐盒，例如 `/musicbox 2` 或 `/musicbox here` |
| `/summon <物种> [营养0-100]` | 往缸里加一条鱼，例如 `/summon koi 100` |
| `/lumens <数量 \| +N \| -N>` | 修改发光尘数量 |
| `/farewell <鱼的名字>` | 让指定鱼进入弥留（大限将至） |
| `/list` | 列出缸里的鱼（名字/物种/年龄） |
| `/star [名字]` | 降一颗星辰（测试用） |
| `/save` | 立刻保存进度 |

实现见 `public/js/commands.js`。想扩展新指令，往 `COMMANDS` 数组里加一条即可（`name / alias / usage / desc / run(arg, T)`），`T` 就是 `window.__tank`。
